# Security policy

PullDay runs commands on your Mac: git, package managers and agent CLIs, sometimes on a schedule. A bug that lets a crafted skill, plugin, marketplace or extension run something it shouldn't is a security issue.

## Reporting a problem

Please don't open a public issue. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. Include what an attacker controls, the steps to reproduce, and the PullDay version from **About** or `Info.plist`.

You'll get a reply within a week. Once a fix ships, you're welcome to be credited in the release notes.

## Supported versions

Only the latest release gets security fixes.
